# NexusMarket

Marketplace desarrollado en Java con Spring Boot.

## Tecnologías

- Java 17
- Spring Boot 4.1.1
- Maven

## Requisitos

- Java 17 instalado
- Maven instalado

## Cómo ejecutar

```bash
./mvnw spring-boot:run
```

## Estructura del proyecto

src/
├── main/
│ ├── java/
│ └── resources/
└── test/
